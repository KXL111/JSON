1.2 启动

调度器启动前（main()，main.c:111）：

  1. dev_status_init()：状态表清零，bd.status = 1（离线），建互斥锁。
  2. term_init()：TERM 队列（4 × text_msg_t，约 13 KB）。必须先建，BD 一启动就可能 term_post()。
  3. bd_init()：BD 队列（2 × text_msg_t）。
  4. 创建 BD 任务。

进入 bd_task() 后：

  1. wdg_register("BD")：登记看门狗，登记时刻算第一次喂狗，3 s 内必须进入主循环。
  2. serial_open(SERIAL_BD, 38400)：建二值信号量 → 开 DMA2 时钟 → GPIO 复用、推挽、上拉 → 接收 DMA 循环模式启动 → 发送 DMA 只配置不使能 → USART 8N1、打开收发 DMA 请求和 IDLE 中断 → 使能。只有堆不够建信号量才会失败，失败后 configASSERT 停机，由看门狗复位。
  3. s_rx_at = now：断线判断从这一刻计时，所以上电后有 5 s 宽限期。
  4. next_icr、next_sq 初值为 0，所以第一圈就发 ICR、刷新 SQ。

1.3 主循环（每圈最长约 20 ms）

for (;;) {
  ① wdg_feed(wdg);                                  // 报平安
  ② n = serial_read(≤256 B, 最多等 20 ms);
     bd_framer_feed() → 每切出一句调用 on_line() → 按类型分发
  ③ if (在途 && 过了 deadline)   finish_send(1, "BD no response (FKI timeout)");
  ④ if (!在途 && BD 队列取到请求) start_send(&s_req);
  ⑤ if (!s_card_ok && 到点)      query_card();     next_icr = now + 5 s
  ⑥ if (到点)                    update_signal();  next_sq  = now + 1 s
}
  • 收到的语句只更新数据；所有定时动作在每圈末尾按 tick 判断。time_reached()（bd_task.c:134）用有符号差值比较，tick 回绕时也正确。
  • ③ 在 ④ 前面：同一圈里先结束超时的那条，再取下一条，保证同一时刻只有一条短报文在途。
  • 串口有数据时 serial_read 立即返回；没数据最多睡 20 ms，可被 IDLE 中断提前唤醒。

1.4 接收链路：串口 → 断句 → 解析 → 分发

serial_read()（serial.c:307）

  • DMA 循环写入 s_bd_rx[4096]。写指针 head = 4096 − DMA 剩余计数（NDTR）；读指针 rx_tail 只由 BD 任务移动。单写单读，不加锁。
  • rx_copy() 遇到跨越缓冲区末尾的数据时分两段拷贝。
  • 先取一次；为空则 xSemaphoreTake(rx_sem, 20 ms)，醒来后再取一次。
  • IDLE 中断（serial.c:380）：先读 SR、再读 DR 清标志（顺带清溢出标志），然后 xSemaphoreGiveFromISR。
  • 余量：38400 波特率约 3.8 KB/s，4 KB 存约 1 s；任务每 20 ms 来一次（这期间只到约 77 B）。万一被覆盖，坏语句会被校验和挡掉。

断句 bd_framer_feed()（bd_proto.c:85）

状态存在 s_framer（line[4352] + len），跨两次读取保存。逐字节处理：

收到处理
$缓冲已以 *hh 结尾（设备没发换行）就先交出上一句；然后清空，开始新句。没收完的半句直接丢掉
还没遇到 $ 的字节丢弃
\r / \n交出当前句；只有一个 $（长度 ≤ 1）的不交
累计超过 4351 字节整句丢弃（没有日志，见 8.3）
其他追加

一段数据处理完时，缓冲已以 *hh 结尾也立即交出，FKI 不必等下一句来了才处理。

on_line()（bd_task.c:575）

  1. 打印原文 BD: rx: ...（CFG_LOG_BD_RAW=1）。PWI、GSS 在 k_periodic 表里，只有 CFG_LOG_BD_PERIODIC=1 才打印。原文必须在解析之前打，因为解析会原地改写这一行。
  2. bd_parse() 失败：打印 BD: bad sentence (checksum should be *XX, or bad format), dropped，丢弃。
  3. 成功：s_rx_at = now、s_rx_bytes_mark = s_rx_bytes。任何类型的有效语句都算"链路活着"。
  4. 查 k_handlers[]：PWI / GSS / ICP / FKI / TCI 各有处理函数；其他类型（SNR、IBD、ACK…）忽略。

bd_parse()（bd_proto.c:161）

  1. 必须以 $ 开头。
  2. 有 *：$ 与最后一个 * 之间所有字节 XOR，必须等于 * 后两位十六进制（大小写都认），通过后把 * 改成 \0。没有 * 的语句不校验，照样接受。
  3. 语句头（第一个逗号之前）至少 4 个字符，取最后 3 个作为类型：不看发送方标识，BD / CC / GN 开头都认。
  4. 逗号改 \0，argv[i] 依次指向各字段，最多 32 个。argv[0] = 协议表的第 1 字段（下标 = 编号 − 1）。
"$BDFKI,032025,TCQ,Y,0,0*77"  →  type "FKI", argc 5, argv = { "032025", "TCQ", "Y", "0", "0" }

1.6 信号：PWI、GSS → SQ、status

PWI（on_pwi()，bd_task.c:344）

$BDPWI,时间,旧体制波束数N,[N 组 × 3 字段],新体制波束数M,[M 组 × 4 字段]*hh
old = atoi(argv[1]);  idx = 2 + old × 3;  new = atoi(argv[idx]);
例：$BDPWI,012430.31,00,03,11,45,45,00,16,49,49,00,21,46,46,00*4B  →  old 0, idx 2, new 3
  • old 不在 0~16 或 idx 越界不更新；new 不在 0~16 也不更新。
  • 只用新体制波束锁定数。design.txt 原写旧体制，但实测旧体制一直是 00，用它 SQ 永远是 0，所以有意改成新体制。
  • 3.md 表 3 里新体制每个波束是 3 个字段（编号、S2C_d、S2C_p 载噪比），111.pdf 截图的实际输出是 4 个；代码只取数量，不受影响。

GSS（on_gss()，bd_task.c:376）

只取 argv[0] 可用卫星数（0~14）。区域短报文模块不输出 GSS，这一路一直没数据。两路都经 sig_update() 记录：计数夹到 0~255，记下 tick，置 seen。

update_signal()（bd_task.c:658，每 1 s）

  1. link = (now − s_rx_at ≤ 5 s)。
  2. 每路 sig_level()：从没收到或超过 5 s 没更新返回 −1，否则 min(数量, 4)。
  3. 两路组合：都有取 (b + s + 1) / 2（四舍五入平均）；只有一路用这一路；都没有为 0。
  4. 串口不通时 SQ 强制为 0。
  5. status：串口不通 → 2 异常；否则 SQ > 0 → 0 在线，SQ = 0 → 1 离线。
  6. 加锁写 bd.sq、bd.status；变化时打 BD: status a -> b (...)、BD: SQ a -> b (beams x, sats y)。
  7. 串口不通、但这期间有字节进来（s_rx_bytes != s_rx_bytes_mark），每 5 s 打 BD: N bytes received on serial but no valid sentence, check baud rate (38400) and wiring；完全没字节不打。

终端侧（TERM 任务，term_task.c）

  1. handle_json()：取 msg_type；缺 msg_id / taskid 各补一个 UUID；用 timestamp 校时。
  2. forward_text(DEV_BD)（term_task.c:314）：取 target_id（≤ 23 B）、msg（\uXXXX 已还原成 UTF-8，≤ 3071 B）。
  3. bd_submit() → xQueueSend(…, 0)：按值拷贝，不等待。

  5. 成功只打 TERM: BD text task <id> -> <号码>, queued，不回复，等 BD 交回结果。

1.8 收报：TCI → 42214

on_tci()（bd_task.c:509）。字段（3.md 表 12）：1 发信方、2 收信方、3 频点、4 时间、5 编码类型、6 数据标识、7 通信数据；少于 7 个忽略。

  1. 打 BD: TCI parsed: from A to B, freq F, time T, code type C, data N chars。
  2. 编码类型 3：bd_mixed_decode() 要求 A4 前缀、长度偶数、全十六进制、还原后 ≤ 2000 B；不满足打 not valid mixed code (A4 + hex), used as plain text。
  3. 类型 1 / 2，或混编解码失败：数据原文当 GBK / ASCII。
  4. gbk_to_utf8()：结果 ≤ 3071 B，在字符边界截断；查不到的码、孤立高字节换成 ?。
  5. TEXT_RECV，peer = 发信方，msg_id / taskid 留空 → term_post()。
  6. TERM 生成两个独立 UUID，发 42214 {taskid, target_id: 发信方, msg}；终端回的 42215 只打日志。本机不向模块回任何收报确认。

1.11 看门狗

BD 每圈 wdg_feed()；WDG 任务每 500 ms 检查，任一登记任务超过 3 s 没报平安就停喂，IWDG 约 4 s（LSI 偏差下 2.7~7.5 s）后复位。BD 单圈最坏阻塞：等数据 20 ms + 等串口发完 ≤ 1.5 s + term_post ≤ 100 ms + 日志（115200 下 1 KB 约 90 ms，最长报文约 0.5 s），都在 3 s 以内。

  • 工具二选一：term_sim.py（附录，会自动解析回复、自动回 42215）；或 SSCOM UDP 窗口（本地 10.9.0.24:5000，远程 10.9.0.57:4220，HEX 关、编码 UTF-8、不加回车换行）。两者都要占 5000 端口，不能同时开。
  • 开机日志依次出现 NET: PHY id 0007:C0Fx …、NET: link up …、NET: up, ip 10.9.0.57 才说明网络正常。

2.3 北斗口（三选一）

接法怎么接适合
A 真模块P4 排针 PC6（TX）/ PC7（RX）→ TTL 转 RS422 模块 → 北斗模块。RS422 两对差分线：本机 TX 对接模块 RX，A/B 不能接反最终联调
B 模拟器（推荐）USB-TTL（3.3 V 电平）直接接 P4：PC6 → USB-TTL 的 RXD，PC7 ← TXD，GND 相连。PC 上跑 bd_sim.py COMx没有模块时跑通整条链路；能复现超时、频度未到等难触发的情况
C 手工同 B 的接线，PC 上用 SSCOM 串口窗口 38400 8N1，手工发 第 4 节 里算好校验和的语句单步验证某一种语句
PC6 / PC7 同时连着摄像头接口 P8（D0 / D1），PC6 还连着 WM8978 的 MCLK：摄像头模块不要插。用接法 B / C 时不要用 5 V 的 USB-TTL。想旁听真模块的通信：RS422 是点对点全双工，用两个只接 RX 的 USB-RS422 分别挂在两对线上，各开一个 SSCOM 窗口。

3.2 手工发北斗语句：校验和怎么算

校验和 = $ 与 * 之间所有字节的异或，写成两位大写十六进制。三种算法：

  1. 让固件告诉你：随便写个 *00 发过去，日志会打 BD: bad sentence (checksum should be *77, …)，照着改。
  2. PowerShell（不用装任何东西，支持汉字，按 GBK 算）：
function BdCks([string]$s){ $x=0; foreach($b in [Text.Encoding]::GetEncoding(936).GetBytes($s)){ $x = $x -bxor $b }; '${0}*{1:X2}' -f $s,$x }
BdCks 'BDFKI,032025,TCQ,Y,0,0'        # 输出 $BDFKI,032025,TCQ,Y,0,0*77
  1. bd_sim.py 的 raw 命令会自动补 $、校验和、换行：raw BDFKI,033000,OFQ,Y,0,0。
SSCOM 发送北斗语句时勾上"加回车换行"（\r\n）。不勾也能处理：断句器见到 *hh 结尾就交出。汉字方式（编码类型 1）的 TCI 里是 GBK 字节，SSCOM 要用 HEX 发送，见用例 18。

7.5 编码方式

TCQ 支持 1 汉字、2 代码、3 混编（另有 4 / 5 压缩）。代码固定用 3 混编（BD_CODE_MIXED），原因：

  • 汉字方式（1）把 GBK 字节直接放进语句：正文里有半角逗号、*、$ 时会破坏语句格式；
  • 代码方式（2）只能发 0~9、A~F；
  • 混编（3）把一切都变成十六进制文本，什么内容都能安全发送。

确需改用其他方式时，改 start_send() 里的编码一步和 BD_CODE_MIXED，并自行过滤正文里的 , * $ \r \n。收报方向 on_tci() 三种都已支持，不用改。

A.1 bd_sim.py —— 北斗模块模拟器

接法见 2.3 的 B。python bd_sim.py COM5，命令见脚本开头的说明。

#!/usr/bin/env python3
"""
bd_sim.py —— 北斗模块模拟器（联调用，没有真北斗模块时代替它）

接线：PC 的 USB-TTL（3.3V）或 USB-RS422 接本机北斗口 USART6（PC6 发 / PC7 收），38400 8N1。
依赖：pip install pyserial
用法：python bd_sim.py COM5

自动行为：
  每秒输出一条 PWI（新体制波束数 = beams）和一条 GSS（可用卫星数 = sats）
  收到 $CCICR -> 回 ICP（卡号 1859836，区域 / 全球频度 60 s，长度等级 3）
  收到 TCQ    -> 打印解出的正文，按 fki 模式 1 s 后回 FKI
  收到 OFQ    -> 1 s 后回 FKI（OFQ,Y）
命令（回车执行）：
  sig <beams> <sats>   改每秒输出的波束数 / 卫星数（sig 0 0 -> 本机判离线）
  silent / talk        停止 / 恢复每秒输出（silent 5 s 后本机判异常）
  fki y|n1|n3|none     对 TCQ 的回执：成功 / 频度未到 / 其他原因 / 不回（测超时）
  tci <发信方> <正文>  发一条混编 TCI 给本机
  raw <语句>           发任意语句，自动补 $、校验和、换行，如 raw BDFKI,033000,OFQ,Y,0,0
  show                 是否打印每秒的 PWI / GSS（默认不打印）
  q                    退出
"""
import sys
import threading
import time

CARD_ID = "1859836"     # ICP 里的本机卡号，TCI 的收信方
ICP_BODY = "BDICP," + CARD_ID + ",0,0,3,0,N,3,N,1,0,0,3,1,60,3,1,1,60,1,0,0,0,0"


def cks(raw):
    """校验和：'$' 和 '*' 之间所有字节的异或"""
    s = 0
    for b in raw:
        s ^= b
    return s


def build(body):
    """'BDFKI,...' -> b'$BDFKI,...*hh\\r\\n'；正文按 GBK 编码，可以含汉字"""
    body = body.strip().lstrip("$").split("*")[0]
    raw = body.encode("gbk")
    return b"$" + raw + b"*%02X\r\n" % cks(raw)


def hhmmss():
    return time.strftime("%H%M%S", time.gmtime())


class Sim:
    def __init__(self, port):
        self.port = port
        self.lock = threading.Lock()
        self.beams = 3
        self.sats = 2
        self.talk = True
        self.show = False
        self.fki = "y"
        self.buf = b""

    def send(self, body, quiet=False):
        data = build(body)
        with self.lock:
            self.port.write(data)
        if not quiet:
            print(">>", data.decode("gbk", "replace").rstrip())

    def later(self, sec, body):
        t = threading.Timer(sec, self.send, args=(body,))
        t.daemon = True
        t.start()

    def periodic(self):
        """每秒调用一次：PWI + GSS"""
        if not self.talk:
            return
        pwi = "BDPWI,%s.00,00,%02d" % (hhmmss(), self.beams)
        pwi += "".join(",%02d,47,47,00" % (11 + i) for i in range(self.beams))
        gss = "BDGSS,%02d,%02d" % (self.sats, 20 if self.sats else 0)
        gss += "".join(",%02d,40,45,180" % (20 + i) for i in range(self.sats))
        self.send(pwi, quiet=not self.show)
        self.send(gss, quiet=not self.show)

    def feed(self, data):
        """本机发来的字节流，按换行切句"""
        self.buf += data
        while b"\n" in self.buf:
            line, self.buf = self.buf.split(b"\n", 1)
            self.on_line(line.strip().decode("gbk", "replace"))

    def on_line(self, line):
        if not line.startswith("$"):
            return
        print("<<", line)
        body, _, given = line[1:].partition("*")
        if given and given[:2].upper() != "%02X" % cks(body.encode("gbk")):
            print("   ! 校验和不对，应为 *%02X" % cks(body.encode("gbk")))
        f = body.split(",")
        kind = f[0][-3:]
        if kind == "ICR":
            self.later(0.2, ICP_BODY)
        elif kind == "TCQ" and len(f) >= 6:
            if f[4] == "3" and f[5][:2].upper() == "A4":
                try:
                    text = bytes.fromhex(f[5][2:]).decode("gbk", "replace")
                except ValueError:
                    text = "(混编数据不是十六进制)"
            else:
                text = f[5]
            print("   TCQ -> %s, 编码类型 %s, 正文: %s" % (f[1], f[4], text))
            reply = {"y": "TCQ,Y,0,0", "n1": "TCQ,N,1,7", "n3": "TCQ,N,3,0"}.get(self.fki)
            if reply:
                self.later(1.0, "BDFKI,%s,%s" % (hhmmss(), reply))
            else:
                print("   (fki none：不回执，本机约 10 s 后判超时)")
        elif kind == "OFQ":
            self.later(1.0, "BDFKI,%s,OFQ,Y,0,0" % hhmmss())

    def command(self, cmd):
        """处理一行命令，返回 False 表示退出"""
        parts = cmd.strip().split(maxsplit=2)
        if not parts:
            return True
        op = parts[0].lower()
        if op == "q":
            return False
        if op == "sig" and len(parts) >= 3:
            self.beams, self.sats = int(parts[1]), int(parts[2])
            print("   每秒输出：波束 %d，卫星 %d" % (self.beams, self.sats))
        elif op in ("silent", "talk"):
            self.talk = (op == "talk")
            print("   每秒输出：%s" % ("恢复" if self.talk else "停止"))
        elif op == "show":
            self.show = not self.show
            print("   打印每秒输出：%s" % ("开" if self.show else "关"))
        elif op == "fki" and len(parts) >= 2:
            self.fki = parts[1].lower()
            print("   TCQ 回执模式：%s" % self.fki)
        elif op == "tci" and len(parts) >= 3:
            data = "A4" + parts[2].encode("gbk").hex().upper()
            self.send("BDTCI,%s,%s,2,%s.00,3,0,%s" % (parts[1], CARD_ID, hhmmss(), data))
        elif op == "raw" and len(parts) >= 2:
            self.send(cmd.strip()[3:].strip())
        else:
            print(__doc__)
        return True


def main():
    import serial    # pip install pyserial

    if len(sys.argv) < 2:
        print(__doc__)
        return
    port = serial.Serial(sys.argv[1], 38400, timeout=0.05)
    sim = Sim(port)
    print("北斗模拟器已打开 %s，38400 8N1。输入 help 看命令。" % sys.argv[1])

    def reader():
        while True:
            data = port.read(256)
            if data:
                sim.feed(data)

    def ticker():
        while True:
            sim.periodic()
            time.sleep(1.0)

    threading.Thread(target=reader, daemon=True).start()
    threading.Thread(target=ticker, daemon=True).start()
    try:
        while sim.command(input()):
            pass
    except (KeyboardInterrupt, EOFError):
        pass
    port.close()


if __name__ == "__main__":
    main()

#!/usr/bin/env python3
"""
term_sim.py —— 终端模拟器（扮演"通信综合管理软件"，经 UDP 和本机交互）

PC 网卡设成 10.9.0.24/24（= app_config.h 的 CFG_TERM_IP）；本机的回复固定发到 10.9.0.24:5000，
所以本脚本绑定 5000 端口（SSCOM 等占着 5000 时先关掉）。
用法：
  python term_sim.py                      交互模式，命令：
      hb                                  发 42201 心跳，打印 42202 里的北斗状态
      bd <号码> <正文>                    发 42212 北斗短报文，等 42213
      raw <json>                          原样发一段 JSON
      q                                   退出
  python term_sim.py hb                   只发一次心跳，等 3 s 后退出
  python term_sim.py bd 4217580 12一二    只发一条短报文，等 15 s 后退出
  --board IP:端口                         本机地址，默认 10.9.0.57:4220
收到 42214（北斗收报）时自动回 42215 确认。
"""
import json
import socket
import sys
import threading
import time
import uuid

BOARD = ("10.9.0.57", 4220)    # 本机 CFG_LOCAL_IP : CFG_TERM_LOCAL_PORT

def make(msg_type, content, msg_id=None):
    return {"msg_id": msg_id or str(uuid.uuid4()), "timestamp": int(time.time() * 1000),
            "msg_type": str(msg_type), "content": content}


def send(sock, obj):
    data = json.dumps(obj, ensure_ascii=False).encode("utf-8")

def show(sock, obj):
    t = str(obj.get("msg_type"))
    c = obj.get("content") or {}
    if t == "42202":
        bd = (c.get("Config") or {}).get("BD") or {}
        print("    BD status=%s SQ=%s CD=%s maxlength=%s taskstate=%s" % (
            bd.get("status"), bd.get("SQ"), bd.get("CD"), bd.get("maxlength"), c.get("taskstate")))
    elif t == "42213":
        err = c.get("errormsg", c.get("error_msg"))
        print("    发送结果 status=%s errormsg=%r" % (c.get("status"), err))
    elif t == "42214":
        print("    北斗收报 来自 %s：%s" % (c.get("target_id"), c.get("msg")))
        send(sock, make(42215, {"taskid": c.get("taskid", ""), "status": 0}, obj.get("msg_id")))


def rx_loop(sock):

        text = data.decode("utf-8", "replace")

def command(sock, line):

#!/usr/bin/env python3
"""
cmp_nocomment.py —— 比对 ye_ch 和 no_ch 两份工程：去掉注释、空行、行尾空白后逐行比较

import difflib
import re
import sys
from pathlib import Path


def strip(text):
    text = re.sub(r"/\*.*?\*/", "", text, flags=re.S)     # 块注释
    text = re.sub(r"//[^\n]*", "", text)                   # 行注释
    lines = [re.sub(r"\s+", " ", ln).strip() for ln in text.splitlines()]
    return [ln for ln in lines if ln]


def main():

        print(__doc__)
        return

            if not fb.exists():

                same = False
                continue

            lb = strip(fb.read_text(encoding="utf-8", errors="replace"))
            if la != lb:
                same = False

                        if d[:1] in "+-" and d[:3] not in ("+++", "---")]

                    print("    " + d)
    print("两份代码一致" if same else "有差异，按上面的提示同步")


if __name__ == "__main__":
    main()
